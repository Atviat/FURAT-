# فُرات | FURAT — Anbar's Smart Map

مشروع أولي لمنصة خرائط وخدمات محافظة الأنبار. يحتوي هذا الإصدار على واجهة عربية RTL وخريطة تفاعلية أولية باستخدام MapLibre وبيانات خرائط OpenStreetMap.

## ما الموجود حالياً؟
- واجهة رئيسية عربية بتصميم داكن.
- خريطة تفاعلية تتمركز تقريباً على محافظة الأنبار.
- تكبير وتصغير وتحريك الخريطة.
- زر تحديد الموقع (يتطلب HTTPS وإذن المستخدم).
- قائمة أولية بمدن الأنبار.
- إعدادات PWA وملف manifest لتجربة الإضافة إلى الشاشة الرئيسية.

## تشغيل المشروع
يتطلب Node.js 20.9 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000

## النشر على Vercel
1. ارفع ملفات هذا المستودع إلى GitHub.
2. افتح https://vercel.com وسجّل الدخول باستخدام GitHub.
3. اختر Add New → Project ثم اختر `furat-anbar`.
4. اترك إعدادات Next.js الافتراضية واضغط Deploy.

## تثبيت الموقع على iPhone
بعد نشر الموقع وفتحه في Safari:
1. اضغط زر المشاركة.
2. اختر Add to Home Screen / إضافة إلى الشاشة الرئيسية.
3. فعّل Open as Web App إن ظهر الخيار، ثم اضغط Add.

## ملاحظات مهمة قبل الإطلاق
- الخريطة الحالية تستخدم خوادم بلاطات OpenStreetMap العامة. هذه مناسبة للتجربة والتطوير المحدود وليست استضافة خرائط إنتاجية مضمونة أو ذات SLA. قبل الإطلاق العام يجب اختيار مزود بلاطات مناسب أو استضافة البلاطات، مع الالتزام بسياسة الاستخدام وإظهار الإسناد.
- بيانات الأماكن والطرق في الأنبار تحتاج جمعاً وتدقيقاً ميدانياً. لا تعتبر هذه النسخة مصدراً معتمداً للطوارئ أو الملاحة الفعلية.
- الملاحة خطوة لاحقة: نحتاج محرك توجيه وبيانات طرق موثوقة واختبارات محلية.
- لا توجد قاعدة بيانات أو حسابات مستخدمين في هذه النسخة بعد؛ سنضيف Supabase/PostGIS بعد تجهيز الأساس.
